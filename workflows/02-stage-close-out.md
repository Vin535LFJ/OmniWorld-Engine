# W02 · 阶段收口（stage close-out）

> **用途**：一个阶段（stage）做完后，把它**真正关掉**——验收、复盘、把素材沉淀成可用的东西。
> **核心原则**：**"代码写完"不是阶段完成。** 收口才是。
> **不重复权威**：Gate 判据自查的细则在 [`workflow-manual.md` SOP-7](../docs/agents/workflow-manual.md)，本规格只写 workflow 层（触发/检查点/产物落点）。
> **当前状态**：阶段 A 已实现完成，但**收口尚未执行**——`CURRENT.md` 正指向这一步。

---

## Trigger

**事件触发**：某阶段的**最后一个切片**标记 `done` 时。

对阶段 A 而言 = 切片 06 完成。对后续阶段 = 各阶段 L1 里声明的最后一片。

## Checkpoint

**两个**：

1. **Gate 验收点**——owner 逐条确认 Gate 判据的"达标 / 未达标 / 部分达标"，特别是**不达标项**。
   brief 形态：一张表（判据 / 及格线 / 实测 / 裁定 / 证据链接），不是报告全文。
2. **素材蒸馏点**——owner 确认 STAR 叙事写对了自己的话（见步骤 4）。

## 输入

- 该阶段的 L1（`docs/design/<stage>/概要设计.md`）§1 阶段目标与出口判据
- 全部切片的 L2 与票据
- `benchmarks/regression/` 下的回归/对齐报告
- `docs/design/problem-log.md`

## 步骤

### 1. 状态核验（W00）

```bash
bash scripts/state-check.sh
```
**完成判据**：退出码 0，或所有非 0 项已记录。

### 2. Gate 判据逐条自查（细则见 SOP-7）

对照 `PLAN.md` §六 的该阶段出口判据，逐条给出「达标 / 未达标 / **部分达标**」+ 证据。

**完成判据**：每条判据都有裁定与证据链接；**未达标项必须显式标注，不得含糊**。
> 先例：阶段 A 的判据 (c) 如实标为 **PARTIAL**（机制级精确、在环面板无法区分），并说明原因与关闭路径。
> 这是**正面示范**——不要为了好看把 PARTIAL 写成 PASS。

### 3. 差异逐条解释

把实测数字与基线并排，**每条差异都要解释**（工作量不同？环境不同？实现不同？）。
**完成判据**：没有未解释的数字。

### 4. 复盘（retro）+ 素材蒸馏

1. 跑 `retro`：面向**环境**提改进候选（导航 / 自动检查 / 编码规范 / 工具经济 / no-op / 信息可达性）。
2. **把候选落盘**——写进 `docs/design/problem-log.md` 或专门的 retro 记录。
   > ⚠️ **这一步是硬性的**。ZCode 的 C1–C6 就是因为没落盘而丢失。
3. **蒸馏 STAR 叙事**：从 problem-log 挑出**反直觉、能体现判断力**的条目（不是技术名词堆砌），
   追加到 `docs/interview-narrative.md`（**单文件累积**，owner 2026-10-15 决定）。

**完成判据**：
- [ ] retro 候选已落盘（有文件路径可指）
- [ ] 每条候选标注了归属（立即做 / 下阶段 / 不做 + 理由）
- [ ] `docs/interview-narrative.md` 至少新增一条，且是**完整 STAR**（情境-任务-行动-结果）

### 5. 更新 `CURRENT.md` 指向下一阶段

**完成判据**：`CURRENT.md` 的"下一件事"指向下一阶段的入口，不再指向已完成的收口。

### 6. 呈现 brief，等 owner 确认

brief = 步骤 2 的裁定表 + 步骤 4 的候选清单（一行一条）+ 下一步入口。

## 输出

- Gate 裁定表（落在 `benchmarks/regression/` 的回归报告中）
- retro 候选（落盘，有路径）
- `docs/interview-narrative.md` 新增条目
- 更新后的 `CURRENT.md`

## 完成判据（Definition of Done）

- [ ] Gate 判据**逐条**有裁定与证据；PARTIAL 如实标注
- [ ] 所有数字差异已解释
- [ ] retro 候选**已落盘**（不是只在聊天里）
- [ ] `docs/interview-narrative.md` 有新增
- [ ] `CURRENT.md` 已指向下一阶段
- [ ] W00 退出码 0
- [ ] 收口产物已提交

## 反模式

| 反模式 | 为什么 |
|---|---|
| 把 PARTIAL 写成 PASS | 破坏整个证据体系的可信度 |
| retro 只在聊天里做 | C1–C6 的下场 |
| 素材蒸馏写成技术名词清单 | 面试官要的是判断力，不是词汇量 |
| 阶段末直接开下一阶段 | 未收口的阶段会变成永久的技术债 |
