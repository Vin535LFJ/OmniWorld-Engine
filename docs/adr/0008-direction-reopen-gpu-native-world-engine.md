# 方向重开：GPU 原生世界引擎为本体，评测降为第一应用（R3 融合）

Status: accepted（2026-10-10）——部分取代 ADR-0007（`docs/99-archive/2026-09-28-docs-slim/01-architecture/decisions/ADR-0007-project-direction.md`）：其"评测优先为身份"的定位与生态 Gate 2/3 止损体系由本 ADR 取代；其架构资产（World Contract、Grounding Loop、评测白地研究）全部保留。

ADR-0007 在生态目标函数（白地/社区采用/中立性）下把"评测 harness"定为项目本体、GPU Runtime 降为地基。2026-10-10 重访访谈确认 owner 的真实目标函数是：**磨练技术 ≳ 敲门砖（AI 相关岗）≫ 创业期权**；资源边界为本地 RTX 4060 8GB + Kaggle 免费 GPU；技术起点为 OpenGL 应用层 + 渲染管线概念，尚无 GPU 代码经验。执行至当时代码库含零 GPU 代码（闭环纯 CPU 1106.7 Hz），2026-08 原始论点——"世界数据以最少拷贝/同步/延迟穿过 GPU 系统"——未被任何代码锻炼：身份漂移与技能停摆同时成立。

决定采 **R3 融合**：身份回归原始论点（GPU 原生世界引擎）；已验证资产（World Contract v0.1、Grounding Loop、五模型 divergence 指标、位级确定性纪律）保留为组织核心与第一应用；评测工具产品化降为**外部信号触发的期权分支**（owner 原话："以后倒是可以做测评的工具"）；路线阶梯为 P2 AI 入环（ONNX Runtime 真模型适配器）→ P3 真实数据入环（NVDEC 视频回放）→ P4 世界模型/智能体应用（含 Kaggle 免费资源训练小模型）；渲染升级（Vulkan 从零写离屏渲染器）为可选技能项目，不在关键路径。

## Considered Options

- **R1 回归原始蓝图本体（丢弃契约/闭环资产）**——拒：白丢已验证资产，CPU 实现仍有对照参考价值。
- **R2 维持评测优先现状**——拒：owner 明确否决（身份不符 + 技能目标停摆）。
- **R4 转向训练模型为主**——拒：与"渲染 + AI 系统"敲门砖叙事不符，且免费资源仅够玩具级训练。

## Consequences

- 旧 Gate 2/3（生态止损）废止；成功判据改为**能力 Gate + 作品集 Gate + 期权触发器 + 时间止损**（连续 3 个月无公开工件 → 缩小范围）。
- 训练边界放宽：免费资源尺度内允许训练玩具级~小模型；付费大算力仍为个人预算红线。旧措辞"不训练任何模型"废止（与 Phase 1 自训 toy MLP 的既成事实矛盾）。
- Phase 0/1 全部成果与 Gate 1 PASS 证据继续有效，作为引擎契约层的第一应用验证。
