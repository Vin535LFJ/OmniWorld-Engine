## 一个先说的重要结论

**"带契约的活世界状态运行时"在 GitHub 上确认没人做**——而且现有项目分成两派，各缺一半：**闭环派**（stable-worldmodel、World-In-World：模型和真环境真的循环交互，但没有共享状态对象）和**状态派**（AutoWorldModel-Bench 的实体状态协议、CARLA 的 tick 快照：有状态协议但没有异构模型闭环）。**OmniWorld = 把这两半接起来。** 这比 09-21 决策时的证据更硬。

## Grounding Loop v0 的零件清单

| 零件 | 用什么 | 许可 | 一句话理由 |
|---|---|---|---|
| 推理底座 | **ONNX Runtime**（微软官方，NuGet 直装） | MIT | 官方维护，Windows+CUDA 即装即用 |
| 感知模型 A（检测） | **RT-DETRv2-S**（官方 ONNX 导出脚本） | Apache-2.0 | 干净许可里最好的小检测器，4060 上 100Hz+ |
| 感知模型 B（深度） | **Depth-Anything-V2-Small**（自己从官方权重导出 ONNX） | Apache-2.0（仅 Small） | 与检测器架构互补；注意大模型版本不可商用 |
| 真值世界 | **自写 ~2 页运动学积分器**；Jolt Physics 留作后期备选 | — / MIT | 决定性（同种子逐位复现）是 thesis 的命根，自写=完全可控 |
| 观察渲染 | **自写 ~200 行 CPU 光栅器**（224×224 平面着色） | — | 这个分辨率下微秒级、零依赖、位级确定；zauonlok/renderer 仅作设计参考 |
| 录制/回放 | **MCAP**（Foxglove 的 C++ writer 就两个文件） | MIT | 白送一个可视化工具（Foxglove Studio） |
| 实体关联 | **Core 内自实现 ~200 行**；ByteTrack-cpp 只读参考 | MIT(参考) | 身份裁决是 Core 的语义，不外包 |

**唯一自写的四处**（积分器、光栅器、关联、WorldState 本体）都是"决定性/契约属于 thesis 核心"的部分——其余全部引用。

## ⚠️ 三条许可红线（已写进正式政策 [`third-party-policy.md`](../03-engineering-lifecycle/third-party-policy.md)）

1. **AGPL（Ultralytics YOLO 全系 / FastSAM / boxmot）**：网络触发 copyleft，产品路径全禁——哪怕它 62k 星。
2. **CC-BY-NC（Depth-Anything 的大模型版本）**：非商用；只有 Small 版安全。
3. **无许可证（tinyrenderer，24k 星）**：没有 LICENSE 文件 = 保留所有权利；只能读思路，一行代码都不能抄。

## 值得抄的设计（不抄代码，抄思想）

- **CARLA**：每个读操作都带 tick 编号的不可变快照——多消费者零锁一致读。
- **Spark-DSG**：分层的活场景图（几何/对象/语义各一层，逐节点带时间戳）。
- **flecs**：把 N 个乱序写入者的修改攒到帧末原子应用——正是我们"所有权裁决"的实现机制。
- **EnTT**：代际实体 ID（ID+版本位，过期句柄自动失效）。

## 🎯 敲门砖通道（Track B 的具体化）

以下仓库都接受外部贡献，贡献点恰好长在我们主线上：

| 目标 | 贡献什么 | 时机 |
|---|---|---|
| WorldMark（MIT） | 新模型适配器；我们的动作词汇先对齐它的 W S A D 词汇表 | Phase 1–2 |
| stable-worldmodel（MIT，2.2k★） | 环境接口适配、评测案例 | Phase 1–2 |
| WBench（MIT，美团/复旦） | 用例包 + 排行榜结果提交 | Phase 2 |
| cosmos-evaluator（Apache-2.0） | 指标 checker、报告接口 | Phase 2–3 |
| WorldFoundry（Apache-2.0） | 先盯防再决定贡献还是差异化 | 更新落地后复盘 |

**被 merge 的 PR = 双轨 Gate 2 的合法通过信号之一。**

## 盯防的两个邻居

- **WorldFoundry**：预告 2026 年 9 月底发"直打交互世界评测"的大更新——落地后一周内必须做对比结论（是威胁、是邻居、还是合作对象）。
- **World-In-World**（ICLR'26 Oral）：闭环评测方向当前最强论文，其统一动作 API 是我们 Action 契约的对齐参照。
