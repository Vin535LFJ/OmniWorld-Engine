> 本篇每个系统都用同一张卡片：**它是什么 / 谁在做 / 现在能用到什么程度 / 和 OmniWorld 什么关系**。所有关键事实都有官方来源（完整来源清单见证据报告 §11）。读完本篇你应该能说清：谁是做什么的、空位在哪里。

## 先建立一个统一画面

2026 年的"世界模型"赛道可以粗略分四层：

```
内容/场景生成 ──► 交互式世界模型 ──► 运行时/状态层 ──► 评测
(给你做一个世界)   (你能走进去/操控它)   (世界状态归谁管、   (这东西到底行不行,
                                       多模型怎么共享)      怎么客观比较)
```

**关键结论：第一、二层挤满了公司和模型；第三层只有 NVIDIA 用专有栈做了工业版；第四层只有一堆互相不兼容的论文脚本。OmniWorld 站在第三、四层的交叉口——这就是它的位置。**

## 玩家卡片

### 🃏 OpenUSD
- **是什么**：3D 场景描述与组合标准（"场景怎么描述/拆分/引用"），Pixar 发明，现在归 AOUSD（Linux 基金会下的开放联盟）管。
- **现状**：定稿了 Core Spec 1.0（2026-08 版）。只管"文件怎么描述场景"，**不管运行时怎么跑、状态谁拥有、AI 模型怎么接**。
- **关系**：不是竞争者。以后 OmniWorld 可能会把状态**导出**成 USD 给别人用（单向、选修）。

### 🃏 NVIDIA Omniverse（含 Mega Blueprint / ovstage）
- **是什么**：NVIDIA 的仿真与数字孪生平台栈。2026 年它已自我定位为 "Physical AI 操作系统"。其中的 **Mega Blueprint** 就是一个已经跑通的"感知 → 世界状态 → 仿真 → 机器人大脑"工业闭环；底层 `ovstage` 是 GPU 常驻的世界状态底座。
- **现状**：库大多源码可见但**专有许可**；闭环是 ROS 2/gRPC 接线、面向工业数字孪生和自家生态。
- **关系**：**工业版 world runtime 已经被它做了，这条赛道不能进。** 但它中立性为零、不服务第三方世界模型——这正是留给开放社区的空档。

### 🃏 NVIDIA Cosmos 3
- **是什么**：开放权重的"全能世界模型"家族（能理解和生成语言/图像/视频/动作），2026-05 发布，三个尺寸（64B/16B/4B），配套一个开源评分器 cosmos-evaluator。
- **现状**：模型+权重+工具链都开放；但最小的能跑的 Cosmos 也要 RTX Pro 6000 / H100 级显卡——**你的 4060 8GB 跑不动**。它的评测是"开环给视频打分"，不是闭环runtime。
- **关系**：不是竞争者，是**被测对象**：以后经"回放数据适配器"接入 OmniWorld 的闭环里接受测量。

### 🃏 Google DeepMind — Genie 3
- **是什么**：2025-08 发布的通用交互式世界模型——给个提示就能生成一个可实时走动的世界（720p、约 24fps、一致性维持几分钟）。
- **现状**：**没有 API**，唯一能碰它的方式是 Google Labs 的消费级实验 Project Genie（2026 年起给 $200/月的 Ultra 订阅者开放）。没有任何"世界状态"暴露给外部系统。
- **关系**：它证明了需求，但不构成竞争也不可用。本项目不依赖它。

### 🃏 World Labs（李飞飞团队）
- **是什么**：做"从图片/文字生成可探索 3D 世界"的公司。产品线：**Marble**（生成持久 3D 世界资产：splat/mesh/碰撞体）、**World API**（REST API，生成出来的世界是可编号、可查询、可导出的持久资源）、**RTFM**（一张 H100 上跑实时交互帧率的生成式世界模型研究预览）、**Atlas**（2026-09 早期访问的下一代 omni 模型）；还收购了一家机器人仿真公司 SceniX。
- **现状**：产品形态是"内容生成 + 资产交付"，不是"活状态的运行时"；但它的官方博客在公开**理论化**这个缺口（"3D as code"一文明确批评黑盒逐帧生成、主张把状态外部化成结构化产物）。
- **关系**：**思想上最接近的竞争者**，需盯防；它的世界资产可以（选修地）作为 OmniWorld 的场景输入。

### 🃏 Decart / Odyssey / Runway 等
- 一句话：都在做"交互式世界生成"，各自融资/估值不低（Decart $300M；Odyssey $1.45B 估值），但全部是"模型中心"——输入控制、输出画面，不暴露世界状态。**它们卖世界，不管"世界归谁管"。**

### 🃏 ROS 2
- **是什么**：机器人界的标准中间件（消息传输、坐标变换 tf2、仿真时钟）。
- **关系**：它解决了"传输和时间"，但没有"实体身份表、世界状态、渲染、AI 模型语义"。本项目 6 个月内不做 ROS 2 桥（Backlog），将来它只会是一个适配器。

### 🃏 评测生态（最重要、也最容易被忽略的一组）
2025–2026 冒出一批**评测交互式世界模型**的学术项目，它们是你的"目标用户原型"：

| 项目 | 一句话 | 来源 |
|---|---|---|
| WorldMark | 统一的 WASD 式控制词汇，每个模型写一个适配器就能测——论文原话："no shared protocol has been established" | arXiv 2604.21686 |
| WBench | 39 个模型、5 维 22 指标的多轮交互评测 + 排行榜（美团 LongCat/复旦） | arXiv 2605.25874 |
| WorldArena | 16 个视频指标 + "功能效用"，带 CVPR 2026 挑战赛 | arXiv 2602.08971 |
| KineBench | 把模型生成的视频里的动作抓回物理仿真器里回放打分（最接近"闭环 vs 真值"） | arXiv 2607.19876 |
| WorldFoundry | 2026-07 开源的"世界模型共享基础设施"（跑模型+评测），首日 317 星 | GitHub OpenEnvision |

**共同点：每一家都自己重写了那套"闭环 + 状态 + 适配器"，而且互不通用。** 没人维护一个大家共用的运行时。

## 空位（white space）结论

> **"开放、中立、面向研究/评测的实时 grounding 闭环 runtime"不存在。** 广义"连接一切"的平台位也不存在——两边都挤满了。OmniWorld 的立锥之地就是把这 ~10 个评测项目重复手写的东西做成开源的、可复现的、能跑的公共底座。

需要诚实标注：没有找到任何人公开喊话"我要一个中立 world runtime"；需求是从"各家重复造轮子 + 论文公开承认碎片化"里推断出来的。所以路线图里埋了止损闸门（第 6/12 个月验证外部兴趣）。
