# Owner Briefing — 项目导读（从这里开始读）

> 这个文件夹是**只给你（项目 owner）看的导读系列**。它不是正式架构文档，不改方向、不定契约——作用是让你重新掌握这个项目。正式决策文档都在别处，这里只做"翻译"和"索引"。

## 你现在的感觉是对的

这轮方向工作给仓库带来了 4 个提交、近百个文件变动（其中约 80 个是"移动进归档"，内容一个字没改）。任何人在一周内遇到这种变化量都会失去掌握——这不是你的问题，是信息没有按"给你读"的方式组织。这个文件夹就是为解决这个问题建的。
