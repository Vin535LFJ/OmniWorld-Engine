# 03: 双模式 CLI + 容差回归框架

**What to build:** 落实 ADR-0009 的运行层：CLI 增加模式开关（默认参考模式，行为与现状逐字节一致）；性能模式 runner 路径；容差比较器（固定 seed → 输出在窗口内）+ 延迟预算断言。用一个注入微小浮点噪声的 stub 适配器自证容差框架有效——不依赖真模型、不依赖 ONNX Runtime。参考模式逐字节路径与全部既有测试保持原样。

**Blocked by:** None（can start immediately）

**Status:** ready-for-agent

- [ ] CLI 模式开关落地；默认参考模式输出与改动前逐字节一致
- [ ] 容差比较器 + 延迟预算断言可用，且由噪声注入 stub 的测试自证（噪声在容差窗口内 → 通过；超窗 → 判红）
- [ ] 性能模式在依赖缺失时给出明确报错并优雅降级，参考模式与既有 ctest 完全不受影响
- [ ] 语义遵循 ADR-0009：参考模式是唯一契约回归 oracle；性能模式数字必须可携带模式 + 环境元数据标注
