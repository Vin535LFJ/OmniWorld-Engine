# Not Now

These topics are valid future directions, but they are not current work.

## Do Not Build Now

- Do not train VLA models.
- Do not train World Models or world foundation models.
- Do not build a complete physics engine.
- Do not build a CARLA, Isaac, Unreal, O3DE, Godot, or game-engine replacement.
- Do not build a full ROS 2 runtime or DDS implementation.
- Do not build Digital Human systems.
- Do not build mobile, Android, or Jetson support.
- Do not build distributed runtime, cluster scheduling, or multiplayer systems.
- Do not build a full editor, asset pipeline, scripting system, or plugin ecosystem.

## Do Not Study Now Unless Required by Current Code

- Advanced robotics control.
- VLA training papers.
- Neural rendering and Gaussian Splatting.
- Ray tracing beyond basic Vulkan awareness.
- OpenCL portability.
- Large-scale simulation platforms.
- LLM agent frameworks.

## Re-entry Rule

A Not Now item can return only through this sequence: Backlog → Research Queue → Roadmap phase → Current Sprint → Code/Experiment/Benchmark.
