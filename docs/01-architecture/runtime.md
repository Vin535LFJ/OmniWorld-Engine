# Runtime Architecture

The Runtime is the core of OmniWorld Engine. It owns application lifecycle, module initialization, execution graph contracts, error propagation, resource lifetime rules, metrics, profiling hooks, and backend capability reporting.

## Current state

Planned. No runtime source code exists yet.

## Planned responsibilities

- Start/stop lifecycle.
- Device and backend capability discovery.
- Resource ownership and lifetime tracking.
- Task graph and scheduling contracts.
- Timestamp propagation.
- Metrics and profiling hooks.
- Adapter boundary APIs.
