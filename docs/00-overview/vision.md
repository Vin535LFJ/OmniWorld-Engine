# Vision

OmniWorld Engine is a GPU-native real-time runtime for connecting media, perception, rendering, simulation, and foundation-model-driven agents through a unified world representation.

## Current / Planned / Proposed / Research

- Current: documentation, research, architecture, knowledge-base scaffolding.
- Planned: C++20/Linux/NVIDIA-first runtime skeleton and benchmark harness.
- Proposed: CUDA/Vulkan interop, NVDEC/NVENC media path, TensorRT inference path, WorldState, Brain adapters.
- Research: ROS 2/NITROS, CARLA, Isaac, OpenVLA, digital-human and neural-rendering applications.
