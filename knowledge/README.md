# OmniWorld Knowledge Base

This directory is the long-term learning and review system for OmniWorld Engine.

## Loop

```text
Research → Understanding → Knowledge Base → Design → Implementation → Benchmark → Lessons Learned → Review → Research
```

## Source labels

- [Project Knowledge]: supported by repository code, docs, benchmarks, or decisions.
- [External Research]: supported by external official docs/papers/repos.
- [Inference]: reasoned from sources but not directly stated.
- [Hypothesis]: plausible but unverified.
- [Experimental]: tested in a spike but not productionized.
- [Verified]: reproduced by repo benchmark or test.
