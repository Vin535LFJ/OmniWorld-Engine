# gpu Knowledge

## Purpose

Maintain project-linked knowledge for gpu: concepts, implementation notes, debugging lessons, performance observations, benchmarks, and review prompts.

## Standard topic template

Use `templates/learning-note.md` for new notes. Every note should mark content as [Project Knowledge], [External Research], [Inference], [Hypothesis], [Experimental], or [Verified].

## Review path

Start with `review/01-basic.md`, then intermediate, advanced, interview, practical, and common mistakes.
